# Mein JavaScript-Projekt — Starter-Template

Das Starter-Template zum Abschlussprojekt des Tutorials **JavaScript V2** im Pantam Learning Universe (PLU).

## Was ist hier schon fertig?

- `index.html` — Grundgerüst mit Header, Main-Bereich und Footer
- `css/style.css` — Start-Stile mit Farb-Variablen (CSS Custom Properties)
- `js/app.js` — Startpunkt für deinen JavaScript-Code

## Deine Aufgabe

Baue dein eigenes Projekt. Du kannst eine Idee aus dem **Projekt-Katalog** wählen oder ein **Eigenprojekt** einreichen:

1. **Highscore-Spiel** — ein Browser-Spiel mit Punktezählung und Highscore-Liste
2. **Formular-Meister** — ein mehrstufiges Formular mit Live-Validierung
3. **Sicherheits-Audit** — eine Demoseite, die typische Web-Schwachstellen zeigt und erklärt
4. **Eigenantrag** — deine eigene Idee (kurz beschreiben und absegnen lassen)

### Anforderungen (Mindeststandard)

- Mindestens **2 JavaScript-Features** (z. B. Validierung, Local Storage, dynamisches Rendern)
- Saubere Trennung: HTML (Inhalt), CSS (Gestaltung), JS (Verhalten)
- **Responsive**: funktioniert am Handy (ab 360 px) und am Desktop
- Veröffentlicht mit **GitHub Pages**

## So arbeitest du (Schritt für Schritt)

1. **Eigenes Repo erstellen:** Oben rechts auf **„Use this template" → „Create a new repository"** klicken. Repository-Name z. B. `mein-js-projekt`, **Public**, Create.
2. **Code auf deinen Rechner holen:** In deinem neuen Repo auf **Code → Download ZIP** → entpacken. (Wer mag: `git clone`.)
3. **In VS Code öffnen** und die `index.html` mit der Live-Server-Erweiterung starten.
4. **Schrittweise bauen** — speichern, im Browser prüfen, Zwischenstände commiten.
5. **Veröffentlichen:** Repo → Settings → Pages → Source: **Deploy from a branch** → Branch `main`, Folder `/ (root)` → Save. Nach 1–2 Minuten läuft dein Projekt unter `https://&lt;dein-name&gt;.github.io/&lt;dein-repo&gt;/`.
